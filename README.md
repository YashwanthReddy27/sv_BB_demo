# SportsVision · basketball training demo site

A static website (plain HTML, CSS and vanilla JS, no build step) for a basketball training facility where every session is filmed and each athlete gets a feedback report.

This is a **demo**: the "analysis" shown is the existing SportsVision proof of concept, meaning pre-computed pose data, pre-rendered analysis videos and the written feedback from the original Streamlit app. Uploading a video runs a simulated job and opens a sample report.

## Run locally

```bash
python dev_server.py 8765      # serves the site and saves form posts to data/submissions.json
# or, static only:
python -m http.server 8765
```

Open http://localhost:8765/

## Deploy

Static hosting from this folder (the repo root). On Vercel: import the repo, framework preset **Other**, no build command, output directory `.`.
The `api/` folder holds two optional serverless functions (`/api/register`, `/api/contact`). They forward submissions to the `FORM_WEBHOOK` environment variable if it is set. Vercel's filesystem is read-only, so they can't save to a file there.

## Structure

```
index.html            Home
pages/                About, Train With Us, Schedule, Academy, Report, My Feedback, Upload, Contact
css/tokens.css        Design tokens (colours, fonts, sizes)
css/components.css    Shared components
css/pages/*.css       Page styles      css/print.css   "Download PDF" print styles
js/site.js            Shell: announcement bar, nav, pop-up, closing band, footer, motion
js/report-data.js     Report model (statuses, deltas, ranked priorities, charts)
js/boards.js          Hand-drawn whiteboard SVG diagrams
js/pages/*.js         One small module per page
js/sportsvision/      Original SportsVision components (synced compare player, 3D joint charts)
data/*.json           ALL editable content: business details, programs, schedule, metrics wording
media/, img/          Session videos, analysis overlays, pose CSVs, posters, logo
```

## Editing content

Everything shown on the site comes from `data/*.json`. Text in `[square brackets]` is a placeholder and appears highlighted on the page until you replace it.

- `site.json`: contact details, socials, hours, footer, links
- `programs.json`, `memberships.json`, `schedule.json`, `announcements.json`, `academy.json`, `coaches.json`, `testimonials.json` (empty hides the section), `faq.json`
- `metrics.json`: metric labels, units, **target ranges**, "why it matters" text and drills. Targets are sample values for the coach to confirm.
- `sample-report.json`: the sample athlete, sessions and written feedback
- `derived-metrics.json`: generated by `tools/derive_metrics.py` in the PoC repo from the existing analysis cache
- `config.json`: `apiMode` (`demo` or `live`), `apiBase`, `externalBooking` (Register links to each session's `bookingUrl`), pop-up delay, upload formats and size limit
